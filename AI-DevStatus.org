* Project Overview
This repo (=bisos/bsip4=) is part of the BISOS platform layer. It provides
provisioning scripts, SBOM (Software Bill of Materials) command services, and
systemd unit seeds for various capabilities deployed on BISOS/Debian systems.

* Maintenance: apt-key Deprecation Fix (Debian trixie)

** Problem
On Debian trixie (13), =apt-key= and =add-apt-repository= / =apt-add-repository=
are no longer present. BinsPrep scripts that added third-party apt repos via the
old =wget/curl ... | apt-key add -= idiom failed with =apt-key: command not
found=, and the subsequent =apt-get install= failed with =E: Unable to locate
package= because the repo was never trusted.

** Fix
Replaced the deprecated idiom with the modern keyrings + =signed-by= mechanism:
download the signing key, =gpg --dearmor= it into a keyring file, and reference
that keyring from the =deb [... signed-by=...]= source list. This matches the
pattern already used in the newer =*-sbom.pcs= files (=git-sbom.pcs=,
=vscode-sbom.pcs=, =ai-claude-sbom.pcs=).
